# Quotapus Icon

Only the files the build needs live here:

| File | Use |
|---|---|
| `AppIcon.icns` | The app icon, copied into the bundle by `script/build_and_run.sh` and `script/release.sh` |
| `icon-1024.png` | The icon shown at the top of the README |

The menu bar mark is `Sources/OpenUsage/Resources/ProviderIcons/openusage.svg`.

The Quotapus name and logo are not covered by this repository's MIT license; see [TRADEMARK.md](../../TRADEMARK.md). The editable brand sources are kept privately by the maintainer. To change the icon, regenerate it there and copy these files back in.
